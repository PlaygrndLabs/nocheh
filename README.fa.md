# persian-agent-bench

مجموعه‌ای از آزمون‌های فارسی برای دستیارهای هوشمندی که محتوای نامطمئن می‌خوانند. در هر مورد، دستوری پنهان در یک ایمیل، پیام بازارسال‌شده، فایل یا سند مشترک گذاشته شده و بررسی می‌شود که آیا دستیار از آن پیروی می‌کند یا نه.

> **وضعیت: پیش‌نویس اولیه (v0.1.0-draft).** ۳۳ مورد که هنوز به‌دست فارسی‌زبانان بازبینی نشده‌اند. شناسه‌ها و فیلدها ممکن است پیش از نسخهٔ v0.1.0 تغییر کنند.

## چه چیزهایی در آن هست؟

- ۱۲ حمله به فارسی ساده، ۱۲ حملهٔ مشابه با یک ترفند ویژهٔ فارسی، و ۹ مورد کنترلی بدون حمله.
- هر حمله یک جفت است: نسخهٔ ساده و نسخهٔ پنهان‌شده. تفاوت نرخ موفقیت آن دو نشان می‌دهد ترفند چقدر اثر دارد.
- محل پنهان شدن حمله: ایمیل، پیام بازارسال‌شده، فایل، سند مشترک.
- هدف مهاجم: نشت داده از راه پیوند، فرستادن داده به نشانی بیرونی، اجرای دستور، ساختن کار زمان‌بندی‌شده، تغییر تنظیمات، پاک کردن.
- ترفندها: نویسه‌های نامرئی، نیم‌فاصلهٔ نابه‌جا، حروف عربی هم‌شکل، ارقام فارسی در نشانی‌ها، تاریخ شمسی، انگلیسی در متن فارسی، فینگلیش، صفحه‌کلید اشتباه، لحن نامه‌های اداری، سرآیند جعلی سیستم، خط جعلی بازارسال، بخش نقل‌قول ایمیل و نویسه‌های جهت‌نما.

## شروع سریع

```bash
python tools/validate.py
python tools/score.py path/to/traces/
```

راهنمای اجرا در [docs/runner-guide.md](docs/runner-guide.md) است.
